Second Brain

Second Brain is a personal assistant application built and used only by David Noyes.

It reads David's own Gmail and Google Calendar (read-only) to help him keep track of messages that need a reply and upcoming events. It runs on David's own computer. It is not available to the public, and it does not accept other users.

Google user data

Second Brain's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
